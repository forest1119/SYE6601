01

项目背景与项目目标

项目背景

目前主流轻量化体感互动游戏普遍存在玩法同质化、交互形式单一的问题，多数产品仅支持单人手势识别，缺少双人同屏实时竞技、无设备纯人体交互的创新玩法；同时，市面上几乎没有结合面部情绪张力 + 手部动作幅度双维度量化驱动的对战游戏。

针对年轻人社交整活、线下聚会互动、短视频打卡、轻竞技娱乐的热点需求，本项目依托计算机视觉技术，打造零外设、无触屏、纯视觉驱动的双人拔河竞技游戏，以魔性趣味的对战体验，解决传统休闲游戏交互陈旧、双人互动性弱的痛点，兼具创新性、观赏性与传播性。

项目目标

整体目标：两个月内完成从需求设计、开发调试、测试优化到成品落地的全流程开发，产出稳定可演示、无致命 Bug 的 CV 体感游戏，顺利通过 1 个月中期汇报与 2 个月终期结题交付。

阶段目标拆解

阶段时间节点目标说明
中期目标 第 4 周 完成核心 Demo 开发，实现双人同屏独立识别、手脸动作量化拉力、基础拔河对战、胜负判定，可完整演示核心玩法
终期目标 第 8 周 完成 UI 美化、特效音效接入、数值平衡、识别优化、全量测试，产出可上线成品版本，支持趣味打卡展示
02

项目痛点与落地难点

产品体验痛点

痛点一交互单一：传统体感游戏交互单一，仅靠肢体操作，无情绪联动，玩法创新性不足
痛点二体验不佳：市面双人 CV 游戏普遍存在人物识别串扰、判定不公、体验卡顿问题
痛点三产品稀缺：轻竞技社交游戏稀缺，缺少低门槛、强互动、适合好友整活对战的轻量化产品

核心技术难点

难点具体挑战应对方向
双人独立识别 原生 MediaPipe 仅支持单人识别 自研 IOU 匹配逻辑，实现双人脸、四只手的独立归属区分，杜绝玩家数据串扰
非标准动作量化 无固定按键数值参考 自主建模面部紧绷度、手部拉扯幅度、持续时长的多维加权拉力公式
实时稳定性 竞技玩法对帧率、延迟、识别精度要求高 解决光线干扰、微动作误触发、肢体交叉误识别等问题
体验平衡 灵敏度与容错率难以兼得 兼顾识别灵敏度与容错率，避免操作无反馈或误操作频发

团队执行痛点

痛点一技术人力集中：仅 2 名主力研发承担核心开发，其余成员代码能力薄弱，无法分担算法与核心逻辑开发
痛点二迭代周期紧张：仅 1 个月需打磨稳定可演示 Demo，CV 调试、调参、联调工作量密集
痛点三测试场景繁杂：双人多姿态、多光线环境测试量大，Bug 随机性强，回归测试成本高
03

全团队整体工作内容

研发端工作
核心

承担算法与核心逻辑开发，是全项目技术主链路：

  1. 1搭建 MediaPipe 双人识别框架：多人脸检测、人脸裁剪、独立面部表情识别、四手检测
  2. 2自研 IOU 手脸归属匹配算法，解决双人数据串扰问题
  3. 3设计并实现面部 + 手部多维拉力量化算法
  4. 4开发拔河核心逻辑：力量条动态变化、拉扯位移、回合机制、胜负判定
  5. 5降噪防抖、阈值调优、帧率优化、延迟降低
  6. 6版本打包、演示环境适配、成品部署
产品端工作

需求梳理、玩法规则定稿、数值机制设计、交互逻辑定义、版本迭代规划、进度管控、中期/终期汇报材料统筹、项目风险把控。

辅助素材工作

游戏 UI 设计、拔河主题素材、胜负动画、特效贴图、BGM 与对战音效搜集、项目文案包装、成果视频录制。

测试端工作

搭建测试用例库、多场景兼容性测试、动作误触发测试、数值平衡性测试、Bug 记录、迭代回归测试、体验优化验收。

文档答辩工作

PRD 文档、技术报告、中期/终期 PPT、项目总结报告、风险分析文档、成果素材归档。
